01

Pegar, ouvir, mudar

3 min
  1. Entenda

    Todo JS de front-end faz 3 coisas: pegar um elemento do HTML, ouvir um evento e mudar algo na tela.

    querySelector('#nome')
    pega pelo seletor CSS: #id, .classe, tag
    getElementById('nome')
    pega pelo id — sem o #
    addEventListener('input', fn)
    roda a função quando o evento acontece
    .value
    o texto dentro de um input
    .textContent
    o texto de qualquer elemento (p, span, div…)
    Quais eventos caem na prova?

    click — clicou (botões)

    input — a cada tecla digitada ou apagada (máscaras!)

    change — quando sai do campo / troca um select

    submit — enviou um formulário

  4. Pratique · complete
  5. Lembre na prova
    • querySelector('#id') com #. getElementById('id') sem #.
    • Ordem sempre: pegar → ouvir → mudar.
    • input.value lê e escreve o texto do campo.
    • Deu null? O id está errado ou o <script> está antes do HTML (coloque no fim do body).
02

Máscaras de input

5 min
  1. Entenda

    A cada tecla (input): limpa tudo que não é número e formata de novo.

    "1a2b3c4"→replace(/\D/g, '')→"1234"→formata→"123.4"
    \dum dígito 0–9
    \DNÃO dígito
    gtodos, não só o 1º
    ( ) $1captura e reusa
    Ler a regex em português

    /(\d{3})(\d)/ = “3 dígitos (grupo 1) seguidos de 1 dígito (grupo 2)”.

    '$1.$2' = “grupo 1, um ponto, grupo 2”. Então 1234 vira 123.4.

    ^ = começo do texto. $ = fim do texto.

  3. Código linha a linha
  4. Pratique · complete
  5. Lembre na prova
